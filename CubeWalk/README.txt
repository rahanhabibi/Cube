CUBE WALK - Android prototype project

What is included:
- Simple 3D ground plane and a small cube player at the center
- Touch virtual joystick in the bottom-left
- Third-person camera that follows the cube
- Keyboard WASD/arrow key controls for testing on desktop
- Godot 4 project, configured for the Compatibility renderer (mobile-friendly)
- GitHub Actions workflow for building an Android APK in the cloud

To get an APK without installing development tools on your computer, follow BUILD_WITH_BROWSER.txt. The workflow uses GitHub's cloud runner to build the APK. It has not yet been run, so a successful build cannot be guaranteed until GitHub Actions completes successfully.
