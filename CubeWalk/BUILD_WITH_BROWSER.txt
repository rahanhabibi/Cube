CUBE WALK — BUILD THE APK WITHOUT INSTALLING SOFTWARE ON YOUR PC

This project includes a GitHub Actions workflow to build the Android APK on a cloud runner.

One-time steps (using a web browser only):
1. Sign in to GitHub and create a new repository named CubeWalk. A private repository is fine.
2. Extract this ZIP using Windows' built-in Extract All option.
3. On the repository page, choose Add file > Upload files. Upload the CONTENTS of the CubeWalk folder (including the hidden .github folder and export_presets.cfg), not the ZIP itself. If the browser does not include hidden folders when selecting files, create .github/workflows/build-android.yml through GitHub's web editor using the workflow file in this project.
4. Commit the uploaded files to the main branch.
5. Open the repository's Actions tab and select Build CubeWalk APK. Choose Run workflow if it did not start automatically.
6. Wait for the workflow to finish successfully. Open its run and download the artifact named CubeWalk-Android-APK.
7. Extract the downloaded artifact ZIP on your PC, then send CubeWalk.apk to your phone and install it. Android may ask you to allow installation from the browser or file manager you used.

Notes:
- No Godot, Android SDK, Java, or other development software needs to be installed locally.
- GitHub Actions availability and usage limits depend on your GitHub account and repository settings.
- This cloud build is not yet tested; if the build fails, open the failed workflow run and share the error log so the configuration can be corrected.
